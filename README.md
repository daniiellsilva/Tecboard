# 🚀 Tecboard

Landing page desenvolvida para apresentar o **Tecboard**, uma plataforma de monitoramento em tempo real com alertas inteligentes para acompanhar a estabilidade de aplicações.

🔗 **Acesse o projeto:** https://daniiellsilva.github.io/Tecboard/

## 📌 Sobre o projeto

O Tecboard foi desenvolvido como uma página de apresentação de uma solução de monitoramento de aplicações.

A proposta é transmitir de forma simples e visual a ideia de acompanhar sistemas em tempo real e receber alertas quando algo importante acontecer.

A página possui uma interface moderna, utilizando fundo escuro e elementos em roxo para destacar a identidade visual da plataforma.

## ✨ Funcionalidades

* 📊 Apresentação da plataforma de monitoramento
* 🔔 Destaque para alertas inteligentes
* 📱 Interface responsiva para diferentes tamanhos de tela
* 🎨 Identidade visual personalizada
* 🖱️ Botão para acesso à versão demo
* 📐 Layout adaptado para desktop, tablet e dispositivos móveis

## 🛠️ Tecnologias utilizadas

* **HTML5** — Estrutura da página
* **CSS3** — Estilização e responsividade
* **Google Search Console** — Verificação e indexação do site
* **GitHub Pages** — Hospedagem do projeto

## 🎨 Design

O projeto utiliza:

* Fundo escuro `#0E1014`
* Roxo `#9747FF` como cor principal
* Fonte **Unbounded** para títulos
* Fonte **Poppins** para textos
* Layout centralizado
* Design responsivo através de `@media queries`

## 📱 Responsividade

O layout possui adaptações para diferentes resoluções:

* 💻 Desktop
* 📱 Tablet
* 📱 Smartphones

Foram utilizadas media queries para ajustar tamanhos de fonte, imagens, espaçamentos e elementos da página.
